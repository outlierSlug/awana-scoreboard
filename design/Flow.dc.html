A games night, end to end
Session status governs what the API will accept. Everything in the middle repeats 4 to 8 times.
Setup
Pick division, optional headcounts. No rounds accepted yet.
Running scoring rules frozen
Rounds are recorded. Every confirmed round pushes to the board instantly.
Finished
Final standings. A round posted now is rejected. Reopen if needed.
Each round
1 · Pick game
Stays selected. The same game usually runs several times.
2 · Tap finish order
One tap per team as it crosses. The only thing done during the race.
3 · Fix it after
Tie, disqualify, not playing. Applied to a row that exists, never a mode set first.
4 · Read the points
The reasoning is shown in words before anything is saved.
5 · Confirm
Never optimistic. The board updates when the server accepts it.
Wrong before confirming? Undo, up to 20 steps.
Wrong after? Void or edit the round. Totals recompute for every team.
